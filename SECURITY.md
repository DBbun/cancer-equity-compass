# Security and data handling

## Supported version

Version 0.1.x is the current research prototype.

## Data boundary

The default deployment is a static browser application. Uploaded files are read
within the active browser tab and are not transmitted by the application. This
does not by itself make a device or hosting environment suitable for controlled
data. Users remain responsible for applicable approvals, data-use limitations,
institutional policy, and NIH security requirements.

Public deployments must contain only synthetic, aggregate, or otherwise
authorized disclosure-controlled material. Never file a public issue containing
participant data, credentials, or security-sensitive configuration.

## Reporting

Report a suspected vulnerability privately to the repository owner. Do not
include controlled-access data in the report.
