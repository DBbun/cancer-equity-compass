Canonical schema reference

A readable guide to the participant-level intermediate schema used by the Auditor. The raw JSON Schema remains available as an explicit developer download.

Not an official CCDI template. This demonstration contract must be mapped to a selected, versioned CCDI resource with NCI/CCDI review before operational use.

Outcome horizon2 years

Time-to-event fields

time_to_event_months ranges from 0 to 24 and event_observed is binary. These fields support engineering demonstrations; a published model adapter must preserve its own eligible population, time origin, censoring rules, outcome, predictors, and horizon.
